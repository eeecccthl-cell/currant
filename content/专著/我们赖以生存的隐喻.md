# 隐喻与文化的连贯性

1、文化中最基本的价值观与其基本概念的隐喻结构相一致。

例如，more is better " is coherent with MORE IS UP and GOOD IS UP.而相反的价值观”less is better“则隐喻结构不一致。

2、我们的价值观并非孤立存在的，而是与我们赖以生存的隐喻性概念共同构成了一个连贯的系统。

# 冲突

为了解释价值观念中的这些矛盾冲突，我们必须发现使用这些价值观和隐喻的亚文化所赋予他们的不同优先权，比如”更多为上“比好为上”的优先权更高，例如“犯罪率正在不断上升。”

哪种价值观被赋予优先权部分取决于我们所处的这个亚文化，另外一部分取决于个人价值观。

主流文化中各种亚文化共享基本价值观，但是赋予这些基本价值观不同的优先权。

在主流文化之外，承载完全不同的价值观的群体中，道德善良和地位可能被重新定义，但仍以不太明显的方式保存了主流文化价值观的主要方位隐喻结构。

例如在僧侣中，物质的多也许是down，但精神的多依旧是up，而精神与物质则构成了，up-down

并非所有文化都会给予“上下”方向优先权，有的文化中平衡与集中发挥着更为重要的作用。

一般来说，主要的方向，上下，里外，核心边缘，主动与被动等似乎跨越所有文化，但是哪些概念被赋予何种方式的方向性，哪些方向又是最重要的，却因文化不同而不同

# 实体和物质隐喻

以物体或物质来理解我们的经验，使得我们可以挑选出部分经验，把他们当做一个统一种类中的离散实体或物质。

一旦我们能够把我们的经验看成实体或物质，我们就能指称它们，将其归类、分组以及量化，从而通过此途径来推理。

事物不是完全离散或者有界限的，我们的目的通常要求我们设置一个认为的界限，以使物理现象一如我们自己一样成为离散的个体，即由一个表面所界定的实体。

本体隐喻：我们对自然物体的经验为非常多样的本体隐喻提供了基础，使我们得以把时间、活动、情感、想法等看成实体和物质的方式。比如说，分家、通货膨胀。

本体隐喻使我得以界定，指称并讨论。

inflation is hacking us into a corner

把通货膨胀看作一种实体，让我们可以指称它，量化它，识别它的特殊方面，把它看成一个原因，对它采取相应行动，甚至可能认为我们理解它。

仅仅把一个非自然事物看成实体或者物质并不能让我们理解的更多，但是本体隐喻能够进行更多的解释。

# 容器隐喻

有界限的物体，无论是人类还是岩石，或是陆地，都有大小。我们可以根据他们所容纳的数量对这些物体进行量化。

物质本身可以被看成是容器。

我们把视野概念化一种容器，并把我们所看到的概念化成这一容器内的物体。

事件、行为、活动、状态

我们借助本体隐喻理解事件、行为、活动以及状态，事件和行为被隐喻性地概念化为物体，活动被概念化为物质，状态被概念化为容器。

are you in the race on Sunday?  race as a OBJECT

are you going to the race? race as object

the finish of the race was really exciting. (finsig as EVENT OBJECT within CONTAINER OBJECT)

总体来说，活动可以被看成内容，也可以被看成容器。

本体隐喻是一种基本的思维方式，是我哦们可以把谈论连绵的现实

相较于概念隐喻，本体隐喻赋予一个较难界定的事物以物质表征或实体

# 拟人

拟人化隐喻：通过人类动机、特点以及活动等让我们理解各种非人类实体的经历。

拟人是一个笼统的范畴，覆盖的隐喻种类繁多，每种隐喻都选取了人的不同方面或者是观察人的不同方式。它们的共同点就是本体隐喻的衍生，让我们根据人类理解世界万象，并能够基于我们的动机来理解万象，

（对于理解复杂现象而言，本体隐喻，拟人化隐喻，提供了一个较为清晰可感的定位。

# 转喻

转喻，用一个实体指代另一个与之相关的实体。

The Times hasn't arrived at the press conference yet.(=the reporter from the TIMES)

这里的转喻metonymy，还包括传统修辞学者称为“提喻”（synecdoche）的手法，即用部分指代整体。

I've got a new set of wheels (=car,motorcycle,etc)

we  need some new bllod in the organization (=new peolple)

隐喻和转喻是不同类型的过程，隐喻主要将一个事物比拟成另一个事物，其主要功能是帮助理解。而转喻的主要功能则在于指代，用一个事物来代替另一个事物。

当然，在部分指代整体的转喻中，我们关注整体的哪个方面，便是强调了整体的哪个方面。

转喻让我们更关注所指事物的某些特定方面。

同隐喻一样转喻概念也不仅是一种诗学手段或修辞手法，也不仅仅是语言的事，转喻概念是我们每天思考、行动、说话的平常方式的一部分。

人脸即人，当我们以脸来感知一个人并基于此感知来采取行动时，我们是在依据转喻运作。

同样的，转喻也是系统化的。

部分转喻整体。
生产者转喻产品
地方转喻事件
机构转喻负责人
操纵者转喻操纵物。

同样，转喻跟隐喻一样，不仅建构我们的语言，也建构了我们的思维、态度和行为。

```
例如，生产者转喻产品，意味着我们不只把产品看作产品，而是同时重视其生产者具有的相关要素。
```

转喻的经验基础要比隐喻更明显，它总是有直接的物理联系或者因果关系。

文化与宗教概念系统本质上是隐喻性的，连贯的隐喻体系赋予宗教及文化以特色，而象征转喻正是联系日常经验与隐喻体系的关键一环。基于我们物理经验的象征转喻，为我们理解宗教和文化概念提供了重要途径。

# 概念，因果关系，部分自发，部分隐喻

### 因果关系

复杂概念，意义大厦，基本材料。因果关系被视为这一基本材料。

我们认为把因果关系感念看作是人类的一个基本概念，从根本上就是错的。因果关系是其他组件的一个群集。

这个群集所形成的整体在人类看来要比其组件各部分更基本

皮亚杰，人类对因果关系的习得原则幼儿时的”直接操控经验“，这些经验包含一组共同的特点，可视之为，原型。

The agent has as a goal some change of state in the patient. The change of state is physical.
The agent has a "plan" for carrying out this goal.
The plan requires the agent's use of a motor program. The agent is in control of that motor
program.
The agent is primarily responsible for carrying out the plan. The agent is the energy source (i.e., the
agent is directing his energies toward the patient), and the patient is the energy goal (i.e., the
change in the patient is due to an external source of energy).
The agent touches the patient either with his body or an instrument (i.e., there is a spatiotemporal
overlap between what the agent does and the change in the patient).
The agent successfully carries out the plan.
The change in the patient is perceptible.
The agent monitors the change in the patient through sensory perception.

这一套既是因果关系的原型——“直接操控“的特点，是因果关系的最佳范例。

这是一个以属性复合为特点的原型因果关系，其他种类的因果关系，虽然不似原型，却具有与原型充分家族相似性的行为或事件，例如：远距离行为，非人类施事，中间施事，两个或更多的施事、非自主的或无法控制的运动程序等。

当与原型的家族相似性不充分时，我们就不会将发生的事件以因果关系特点待之，或至少对其因果关系特点提出质疑。

这里的原型，是罗希人类范畴化理论理论中的意义，（它是确定一元素是否属于该范畴的参照点。

尽管因果关系概念对我们人类的活动来说是基本的，但它并非不可分析和不可分解的。既然因果关系概念被依据原型定义为一个复现的特征的复合体，它就是整体，也是可被分析成那些特征，拥有广泛形式的变体。

我们的概念可以同时是基本的，整体的，以及可无限分析的。

（基本的意味着，概念在人类生活中不言自明的重要性
（整体意味着，这一概念是一个复现的特征的复合体，其整体被认为比部分更为基本
（可无限分析意味着，复合体本身拥有无数变体，超于概念原型进行的衍生运用是一个隐喻性的过程

### 因果关系原型的引申隐喻

制作（making）一个物体的简单例子，都是直接因果关系（direct causation）的特定情形。它们全都包含典型的“直接操控”（direct manipulation），以及上面列出的所有特性。

但是这里有一个额外的特定，作为制作making的例子，区别于因果关系。

物体做为操控的结果，被我们视为一个不同种类的东西（thing）。
一张纸做成一个纸飞机，我们把前后两者划分进不同的种类，它们有不同的形式和功能。

即便是简单的状态转变，例如水变成冰，也被视为一个制作的实例，因为水和冰有不同的形式和功能。

```
• You can make ice out of water by freezing it. 
• I made a paper airplane out of a sheet of newspaper. 
• I made a statue out of clay. 
```

”从一种状态转变为另一种（into another），获得新的形式和功能“我们将这种类型的改变概念化为这一隐喻：

```
THE OBJECT COMES OUT OF THE SUBSTANCE.

物体脱出于物质。
```

范畴化在真理中的作用

为了了解世界并在其中发挥作用，我们不得不对我们遇到的事情和经验以对我们有意义的方式进行范畴化。

我们的物体范畴有其自然维度，知觉维度（基于我们的感觉器官对物体的构想）；肌动活动维度（基于物体之间的运动交互特性）；功能维度（基于我们对物体功能的构想）；目的维度（基于特定情况下我们对物体的使用）。

我们对各种物体的分类至少包含这些维度的完形，每一个自然维度都指明一种互动属性。
（也就是，指向人的感官能力和实践）

范畴化是通过突显某些特征，淡化其他特征或是隐藏其他特征来表示一种物体或经验类型的自然方法。每个维度都提供一些特性来加以突显。而突显某些特征必定会淡化或者隐藏其他特征，这是我们进行范畴话时经常会遇到的情况，专注一组特征转移了我们对其他特征的注意。

每一句真实陈述都必然忽略其中的范畴所淡化或隐藏的特性。

由于范畴的自然维度来自于与世界的相互作用，那么这些范畴所给出的特性就不是事物本身的特性，而是以人的知觉器官、功能概念等位基础的互动特性。因此，通常以人类的范畴所作的真实陈述断言的并不是事物本身的特性，而只是相对于人类机能有意的互动特性。

```
比如，人们会说“轻于鸿毛”，但一般不会关注鸿毛的红外线反射率。因为，“轻重”是对日常生活有意义的知觉互动属性。
```

我们的范畴不是严格以事物本身所固有的特性来划分的，怎样才算术语一个范畴取决于使用范畴的目的。一个申述是否真实取决于陈述中所使用的范畴是否合适，因此，陈述的真理是相对于特定情境下针对我们的目的来理解范畴的方式而言的。

脱离了人的目的，句子是没有真假的。真理无法脱离语境。

```

```

# 相似性问题

隐喻通常不是基于相似性，而是基于我们经验中的跨域关联，这导致隐喻中两个域之间的感知相似性。持续使用一个隐喻可能会产生感知相似性。

即使我们最深切和最持久的概念，如时间、诗经、因果关系、道德和心灵本身，也是通过多重隐喻得以理解的，并通过多重隐喻来推理的。

在每一种情况下，一个概念域（如时间）是通过另一个域（如空间）的概念结构来推理和谈论的。

概念隐喻系统不是任意的，也不是历史偶然，而是极大程度上有我们身体的共同性质和我们在日常世界中运作的共同方式塑造的。

甚至物理学和社会科学中用到的因果关系概念基本都是有仅两打不同的隐喻组成的，每个都有其自身的因果逻辑。

# 范畴化

为了了解世界并在其中发挥作用，我们不得不对我们所遇到的事情和经验以对我们有意义的方式进行范畴化。

我们物体的范畴有起自然的维度：

```
知觉维度——基于我们的感觉器官对物体的构想；
肌动维度——基于物体之间的运动交互的特性
功能维度——基于我们对物体功能的构想
目的维度——基于特定情况下我们对物体的使用。
```

我们对各种物体的分类至少包含这些维度的完形，每一个自然维度都指明一种互动属性。

同样我们将事件、活动，以及其他经验范畴化是也依据一些自然维度。

范畴化是通过凸显某些特征，淡化其他特征或是隐藏其他特征来标识一种物体或经验类型的自然方法。每个维度都提供一些特性来加以突显。

我们所做的真实陈述时基于我们范畴化事物的方式，从而也就是基于这些范畴的自然维度所突显的特征。每一句真实陈述都必然忽略其中的范畴所淡化或隐藏的特性。

由于范畴的自然维度来自于与世界的相互作用，那么这些范畴所给出的特性就不是事物本身的特性，而是与人的直觉器官、功能概念等为基础的互动特性。因此，通常以人类的范畴所做的真实陈述断言的并不是事物本身的特性，而只是相对于人类机能有意义的互动特性。

一个陈述只有相对于某一种理解时才为真

理解通常会涉及人类的范畴化，这种范畴化是互动特性以及源于经验的维度在发生作用。

为真的陈述与陈述中的范畴所凸显的特征有关。

范畴既不是固定的，也不是统一的，而是通过原型或与圆形的家族相似性来界定的。出于不同目的，在情境中可以进行调整。

陈述的真假取决于陈述中采用的范畴是否合适，有相应的随着目的和情境的其他方面发生变化。

# 相似性的产生

我们所感知到的许多相似性都是作为我们概念系统一部分的常规隐喻的结果。

本体隐喻产生相似性

结构隐喻归纳相似性：隐喻性建构使我们凸显了某些经验，好像这是我们唯一的经验，这样做时便在两种经验之间建立起一系列相似性。

结构相似性：关涉我们理解各个被突显的经验是如何连贯的吻合到一起的方式。只有这种连贯结构使我们能够了解突显的经验之间的相关性是什么以及蕴涵如何关联。

经验的突显范围被挑选出来视为连贯。没有隐喻，对你来说这种经验范围就不会作为可识别的连贯经验集合而存在。

隐喻通过赋予一个经验范围以连贯结构来创造出新的相似性。

吸收思想和消化食物之间的相似性只有在从进食的经验角度理解思考经验是才能感觉到。如果以其他的隐喻来概念化理解过程，这种精确的相似性便不存在了。

隐喻创造相似性的方式可以总结如下：

1、常规隐喻（方位隐喻，本体隐喻，结构隐喻）通常是基于我们在经验中察觉到的相互关系。

```
例如，在我们的工业文化中，完成一项任务需要“时间”和“劳动”相互关联，而这两者又同时与物质资源的投入和产出相关联，因此我们把“劳动力“和”时间“从隐喻角度看作”资源“，并由此看到它们之间的相似性，这种关联是其中的原因之一。

（如，在工厂劳动中，不会把人的情感能力视为一种资源。但在服务行业，情感能力就有可能被视为一种资源。因为此时情感能力，时间，劳动，投入，产出，是在经验上关联的。）

关联不是相似性。基于这种经验中的关联而产生那些隐喻，依据我们所感知的相似性来定义概念。
```

2、结构变化的常规隐喻可能是基于又方位隐喻和本体隐喻引出的相似。

3、新隐喻主要是结构隐喻，它们可以向结构性的常规隐喻那样创造相似性。也就是，它们同样基于来自本体隐喻和方位隐喻的相似性。

4、隐喻使得我们通过该隐喻所引发的全面结构相似性来找到这些孤立相似性之间的连贯。

# 传统的对比论

```
• 隐喻是语言问题，不是思想和行为问题。没有隐喻想象和行为这一回事。

• A是B形式的隐喻是一种语言表达，意思与对应的语言形式”A像B，在X，Y，Z….方面“。”X,Y,Z…"这些方面就是我们所说的“孤立的相似性”

• 由此得出，隐喻只能描述存在的相似，不能创造相似。
```

我们与对比论的不同：

隐喻首先是思想和行为问题，语言问题仅是派生问题。

隐喻可以以相似性为基础，但在很多情况下，这些相似性是基于不以相似性为基础的常规隐喻（方位隐喻，本体隐喻，结构隐喻）。

虽然隐喻可以部分基于孤立的相似性，但是，我们认为这些重要的相似性都是由隐喻创造的。

我们的立场是：

我们认为固有特性和相似性都存在，而且只有在与一个概念系统相关时才能体验到，因此，与隐喻相关的唯一相似性是经验相似性，而不是客观相似性。

概念隐喻基于我们经验中的相互关联，这些经验关联由两类：经验同现和经验相似。

自然就没有相似性，而是分散的感官体验，一段段行动流。

隐喻创造了相似性，突显聚焦于一个连贯的经验结构，并塑造行为。

比如说，思想的过程是建筑施工的过程，要有稳固的地基（对应丰富的基础知识），建筑蓝图（对应逻辑结构），空间结构（对应内容），内部联通（对应各种知识的内在联系），空间功能（对应意图与功能）等等。此时，思想和食物就没有什么相似性了

这种相似性，作为隐喻建构的结果，可以称之为，连贯的内涵相似性，与使隐喻之所以可能的互动属性的感官经验相似性截然不同，（孤立的相似性）

（而方位隐喻和本体隐喻有各自有经验的身体性的基础。）

结构变化的常规隐喻（概念隐喻），赋予结构
方位隐喻、本体隐喻，投射 （投射不以相似性为基础，而是我们思维的方式）
经验 基础

未经隐喻建构的经验相似性是孤立的，有待体验的。

```

```
突显了一个连贯的经验结构，可以用于推理和运作。

问题（物质）总会“再次结晶”（出现），我们也需要再次“溶解”（解决）问题，这是“自然的现象”。
